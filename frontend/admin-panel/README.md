# پنل ادمین (Admin Panel)

پنل مخصوص حساب‌های نقش ADMIN — بررسی و تأیید/رد/مسدودسازی پروفایل مراقبان.

## اجرا

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

## دامنه فعلی (فاز اول — بدون سیستم شکایت)

طبق تصمیم صریح: بخش «رسیدگی به شکایت» از دامنه ADMIN عمداً در این فاز
ساخته نشده (نیازمند apps.reviews/Complaint که هنوز وجود ندارد). آنچه
ساخته شده:

- **صف بررسی مراقبان** — فهرست، جست‌وجو، فیلتر بر اساس وضعیت
- **تأیید / رد** — از قبل در بک‌اند وجود داشت، این پنل اولین UI واقعی
  برای آن‌هاست
- **مسدودسازی (بلک‌لیست) / رفع مسدودیت** — تازه ساخته شده؛ از
  `CaregiverStatus.SUSPENDED` استفاده می‌کند که در enum وجود داشت اما
  هیچ endpoint ای به آن نمی‌رسید. یک مراقب مسدودشده به‌طور خودکار از
  تمام نتایج تطبیق (چه پلتفرمی چه مخصوص یک آژانس) حذف می‌شود، بدون
  نیاز به کد اضافه در موتور تطبیق.

## ساخته‌شده با shared-ui

این پنل اولین پنلی است که کامپوننت‌های پایه‌اش را از `frontend/shared-ui`
کپی کرده (نه از یک پنل دیگر مستقیماً) — طبق قرارداد مستندشده در
`shared-ui/README.md`.
