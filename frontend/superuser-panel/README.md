# پنل سوپریوزر (Superuser Panel)

پنل مخصوص حساب‌های نقش SUPERUSER — تنها نقشی که مجاز به تغییر نقش سایر
کاربران است، طبق مدل RBAC پلتفرم.

## اجرا

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

بک‌اند (Django) باید همزمان روی `http://localhost:8000` در حال اجرا باشد.

## دامنه فعلی (فاز اول)

این فاز عمداً محدود به یک قابلیت است که پیش از این هیچ‌جا در دسترس نبود
(حتی از طریق پنل‌های دیگر): **فهرست/جست‌وجوی کاربران و تغییر نقش آن‌ها**.
پیش از این، تنها راه تغییر نقش یک کاربر، Django admin بود.

- **ورود** → **داشبورد**: جست‌وجو با نام/نام کاربری/شماره موبایل، فیلتر
  بر اساس نقش، و تغییر نقش هر کاربر
- بک‌اند: `GET /api/auth/users/` (جدید) + `PATCH /api/auth/users/<id>/role/`
  (از قبل موجود و تست‌شده)

## محافظت‌های امنیتی اضافه‌شده

چون این پنل تغییر نقش را به یک کلیک تبدیل می‌کند، دو محافظت جدید به
`RoleChangeService` اضافه شد که پیش از این وجود نداشت:

- یک سوپریوزر نمی‌تواند نقش **خودش** را تغییر دهد (جلوگیری از قفل‌شدن
  تصادفی خارج از حساب).
- **آخرین** حساب سوپریوزر باقی‌مانده پلتفرم قابل تنزل‌رتبه نیست — باید
  ابتدا یک سوپریوزر دیگر ساخته شود.

## آنچه در این فاز نیست

مدیریت تنظیمات سراسری پلتفرم (بخش دیگری از دامنه SUPERUSER طبق سند
معماری) — این فاز فقط روی مدیریت کاربران/نقش‌ها متمرکز است.
