# پنل خانواده (Family Panel)

پنل مشتری‌محور برای اعضای خانواده — ثبت‌نام، مدیریت اطلاعات سالمندان
تحت نظر، تکمیل پرسشنامه سازگاری، و اشتراک‌گذاری دسترسی با سایر اعضای
خانواده (مثلاً چند فرزند که هرکدام باید به پرونده والدین خود دسترسی
داشته باشند).

## اجرا

```bash
npm install
cp .env.local.example .env.local   # در صورت نیاز آدرس بک‌اند را تغییر دهید
npm run dev
```

بک‌اند (Django) باید همزمان روی `http://localhost:8000` در حال اجرا باشد.

برخلاف پنل ناظر (که مراقبان توسط یک ناظر وارد سیستم می‌شوند)، خانواده‌ها
خودشان ثبت‌نام می‌کنند — صفحه ورود شامل گزینه ثبت‌نام مستقیم است.

## معماری

- **جریان کار**: ثبت‌نام/ورود → داشبورد (لیست سالمندان) → افزودن سالمند
  → صفحه سالمند با سه تب: اطلاعات پایه، پرسشنامه سازگاری، دسترسی خانواده.
- **دسترسی چندنفره**: هر سالمند می‌تواند توسط بیش از یک عضو خانواده
  (مثلاً چند خواهر و برادر) مدیریت شود — از تب «دسترسی خانواده» در صفحه
  هر سالمند قابل مدیریت است. عضوی که اضافه می‌شود باید از قبل در پلتفرم
  ثبت‌نام کرده باشد.
- بسیاری از کامپوننت‌های فرم (`components/forms/*`) دقیقاً همان
  کامپوننت‌های اثبات‌شده در `supervisor-panel` هستند — تقویم شمسی و
  انتخاب استان/شهر/منطقه، بدون بازنویسی از صفر.
- تم رنگی این پنل صورتی ملایم (pastel pink) است، متفاوت از تم بنفش/نیلی
  `supervisor-panel` — یک تصمیم طراحی آگاهانه برای تمایز پنل مشتری از
  پنل ادمین.

## سه سؤال پرسشنامه هنوز نیاز به تأیید محصول دارند

`meal_time_strictness`، `medication_timing_priority`، و
`willingness_to_express_opinion` در بک‌اند با متن هشدار مشخص شده‌اند —
سند منبع فقط «گزینه‌ای» نوشته بود بدون مشخص کردن گزینه‌های واقعی.
فعلاً از مقیاس IntensityScale استفاده می‌کنند به عنوان نزدیک‌ترین
گزینه ممکن.
