# صفحه فرود (Landing Page)

صفحه معرفی عمومی «مراقب من» — توضیح می‌دهد پلتفرم چیست و کاربر را به
پنل درست (خانواده، بیمار، مراقب، یا ناظر) هدایت می‌کند. خودش هیچ
داده‌ای از بک‌اند نمی‌خواند یا نمی‌نویسد — کاملاً استاتیک است، فقط
لینک‌دهی به پنل‌های دیگر.

## اجرا

```bash
npm install
cp .env.local.example .env.local   # آدرس واقعی هر پنل را در پروداکشن تنظیم کنید
npm run dev
```

## آدرس پنل‌ها

در دیتای پیش‌فرض `.env.local.example`، هر پنل روی پورت جداگانه‌ای در
localhost فرض شده (مطابق با تنظیمات توسعه محلی این پروژه). در
پروداکشن، این متغیرها را به دامنه یا زیردامنه واقعی هر پنل تغییر دهید
(مثلاً `https://family.moraqebeman.ir`).

## چرا صفحه جدا؟

سه پنل دیگر (`family-panel`، `patient-panel`، `caregiver-panel`) هرکدام
مستقیماً با فرم ورود خودشان شروع می‌شوند — مناسب کسی که می‌داند دقیقاً
کجا باید برود. این صفحه برای کسی است که تازه با «مراقب من» آشنا
می‌شود و باید اول بفهمد کدام پنل برای اوست.
