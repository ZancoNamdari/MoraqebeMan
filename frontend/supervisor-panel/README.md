# پنل ناظر (Supervisor Panel)

ابزار موقت برای ورود سریع اطلاعات مراقبان توسط یک ناظر — طراحی‌شده برای
پروژه‌ای مشخص: ورود دستی اطلاعات ۴۰-۵۰ مراقب طی یک دوره کوتاه (چند روزه).

## اجرا

```bash
npm install
cp .env.local.example .env.local   # در صورت نیاز آدرس بک‌اند را تغییر دهید
npm run dev
```

بک‌اند (Django) باید همزمان روی `http://localhost:8000` در حال اجرا باشد.

ساخت یک حساب ناظر (اگر هنوز ندارید):
```bash
# در پوشه backend/
python manage.py create_admin --username supervisor1 --password "..."
```

## معماری

- **جریان کار**: ورود → داشبورد (لیست مراقبان + پیشرفت) → افزودن مراقب جدید
  (فرم پایه → فرم ۱ هویتی → فرم ۲ شرایط همکاری → فرم ۳ سوابق و مهارت →
  فرم ۴ معرف‌ها) → می‌توان مراقب بعدی را بلافاصله شروع کرد.
- تمام گزینه‌های چندانتخابی (`lib/constants.ts`) مستقیماً از
  `backend/apps/caregivers/choices.py` رونویسی شده‌اند — در صورت تغییر
  گزینه‌ها در بک‌اند، این فایل هم باید به‌روزرسانی شود.
- بک‌اند این پنل را از طریق مسیرهای `/api/supervisor/caregivers/...`
  پشتیبانی می‌کند (نه `/api/caregivers/me/...` که مخصوص ورود اطلاعات
  توسط خود مراقب است) — این دو کاملاً مستقل از هم‌اند.

## وضعیت

این یک ابزار **موقت** است، نه بخش دائمی محصول — عمداً ساده نگه داشته
شده (بدون مدیریت state پیچیده، بدون کتابخانه فرم مجزا) چون قرار است
پس از پایان دوره ورود اطلاعات کنار گذاشته شود.
