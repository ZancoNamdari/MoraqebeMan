# پنل مراقب (Caregiver Panel)

پنلی که یک مراقب با آن بیماران تخصیص‌یافته به خود را می‌بیند و گزارش
مراقبت (دارو، تغذیه، علائم حیاتی، حادثه و...) برای هرکدام ثبت می‌کند.

## اجرا

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

بک‌اند (Django) باید همزمان روی `http://localhost:8000` در حال اجرا باشد.

## این پنل خودثبت‌نامی ندارد

برخلاف پنل خانواده، مراقبان توسط یک ناظر در `supervisor-panel` وارد
سیستم می‌شوند (نام کاربری به‌صورت خودکار ساخته می‌شود و رمز عبور تصادفی
است که خود مراقب هرگز نمی‌بیند). صفحه ورود این پنل شامل جریان «بازیابی
رمز عبور» است — همین جریان هم اولین ورود مراقب را ممکن می‌کند و هم
فراموشی رمز بعدی را.

## جریان کار

داشبورد فقط بیمارانی را نشان می‌دهد که یک ناظر از طریق
`POST /api/care/assignments/` این مراقب را به آنها تخصیص داده باشد —
هیچ مراقبی نمی‌تواند برای بیماری که به او تخصیص داده نشده گزارش ثبت
کند (این محدودیت در بک‌اند اجرا می‌شود، نه فقط در رابط کاربری).

## وضعیت

`caregiver-panel` عمداً محدودتر از `family-panel` طراحی شده — فقط
مسیرهای «بیماران من» و «ثبت گزارش» را پوشش می‌دهد، نه فرم‌های کامل
هویتی/شرایط همکاری مراقب (که از قبل توسط ناظر در `supervisor-panel`
تکمیل می‌شود).
